#  Python Pandas Learning Repository

Dive into practical examples and explorations using **Pandas**, the powerful Python library for data manipulation and analysis.

---

##  Contents & Highlights

- **Data Loading** — Read data from CSV, Excel, JSON, and SQL sources.
- **Data Cleaning** — Handle missing values, filter rows, transform columns.
- **Exploration & Aggregation** — Grouping, summary statistics, pivot tables.
- **Time Series Analysis** — Date parsing, resampling, rolling calculations.
- **Merging & Joining** — Combine datasets using merge, concat, and join.
- **Feature Engineering** — Create new columns, apply functions vectorized over data.
- **Visualization** — Plot line charts, histograms, bar plots using Pandas and Matplotlib.
